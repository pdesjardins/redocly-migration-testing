# API reference

The Toast API reference includes detailed information about the endpoints,
parameters, responses, and data types for Toast APIs.

Use this API reference to find specific information about Toast API functions
while you build and maintain your Toast platform integration. You can get more
development guidance and context from these additional Toast platform resources:

* [Start-to-finish recipes to get your integration implemented and live in the
  _Integration cookbook_](https://doc.toasttab.com/doc/cookbook/index.html)

* [Guides and code examples to help you build integration functions in the
  _Developer guide_](https://doc.toasttab.com/doc/devguide/index.html)

* [Detailed information about Toast restaurant business functionality in the
  _Platform guide_](https://doc.toasttab.com/doc/platformguide/index.html)
